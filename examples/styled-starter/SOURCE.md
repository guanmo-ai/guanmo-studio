# 程序卡面入门配置

内容为本项目的占位示例。七张卡片均有 `face`，沿用 GIF Factory 参考片的暖棕背景、轻薄结构和程序卡背。使用项目图片时给相应卡片添加 `front: "image"` 和 `image`，正面显示原图，卡背继续使用 `face`。

示例启用默认配乐和 CC0 音效。自备配乐和音效分别通过 `audio.music.path` 和 `audio.sfx.path` 指定。占位文案和品牌随项目替换。 [配乐来源](../../templates/card-carousel/assets/audio/MUSIC.md) · [音效来源](../../templates/card-carousel/assets/audio/SFX-LICENSES.txt) · [MIT 许可](../../LICENSE)
