# 程序卡面入门配置

内容为本项目的占位示例。七张卡片均有 `face`，沿用暖色舞台、轻薄结构和程序卡背。使用项目图片时给相应卡片添加 `front: "image"` 和 `image`，正面显示原图，卡背继续使用 `face`。

默认启用模板的原创合成配乐和 CC0 音效。 [配乐来源](../../templates/card-carousel/assets/audio/MUSIC.md) · [音效来源](../../templates/card-carousel/assets/audio/SFX-LICENSES.txt)自备配乐和音效分别通过 `audio.music.path` 和 `audio.sfx.path` 指定。占位文案和品牌应随项目替换。配置和内置原创合成配乐采用仓库 [MIT 许可](../../LICENSE)。
