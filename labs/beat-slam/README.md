# Beat Slam 节拍快闪（已否掉的实验，留作存档）

120 BPM 逐拍大字、硬切蒙太奇、主角推近、数字冲击、首尾循环。纯 DOM，15 秒片子约 30 秒渲完。

主人评价："像会动的 PPT"，没有大片质感，不作为主片方向。保留它是因为 DOM 逐帧渲染的做法（`render.cjs`：seek → 截图 → FFmpeg）和 [IDEAS.md](IDEAS.md) 里的几条模板思路以后可能还用得上。

当前主线是 Blender 路径追踪的《月下荒原》，在仓库 guanmo-ai/design-style-film（分支 `claude/film-v1`）。

素材（`assets/`）和字体（`../fonts/`）未入库：字体取自本仓库 `assets/fonts/`，素材是工作台截图和 Studio Demo 的取帧。
