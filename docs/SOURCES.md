# 素材来源

Studio Demo 的文案、程序卡面与背景由 Guanmo Studio 提供。「数字地平线」的样片和封面由模板代码生成。示例的具体出处见各自的 `SOURCE.md`。 [Studio Demo](../examples/studio-demo/SOURCE.md) · [数字地平线](../examples/digital-horizon/SOURCE.md) · [背景](backgrounds.md)

## 字体

渲染使用 Noto Sans SC、Instrument Serif、Geist 和 JetBrains Mono。网页使用 Geist 和 Geist Mono。字体各自的 SIL Open Font License 与版权声明随文件保留。 [许可证清单](asset-licenses.json)

## 声音

- 默认配乐是 Guanmo Studio 的 15 秒原创合成轨。随附 Python 脚本可重建。 [配乐来源](../templates/card-carousel/assets/audio/MUSIC.md)
- `sfx.wav` 是从 Design Style 原片工程保留的独立音效分轨。其使用的 CC0 声音逐一列在声明中。 [音效素材与许可](../templates/card-carousel/assets/audio/SFX-LICENSES.txt)
- `sfx-synth.wav` 使用项目的合成脚本和默认时间表生成。 [音效生成](sound-effects.md)

## 创作者案例

《GIF 工厂 · 电影片头》是网站上的卡片转盘案例，原片与封面按案例展示。Studio Demo 提供可重建的随包示例。Design Style 是卡片转盘的早期创作者案例，相关原图和配乐分别归其权利人。 [GIF 工厂案例来源](../examples/gif-factory-case/SOURCE.md) · [Design Style 项目](https://github.com/guanmo-ai/design-style)

网站播放器使用各案例成片转制的 `web-preview.mp4`（720p、30 fps），原始成片和预览的来源许可一致。模板卡片所列规格用于制作导出。
